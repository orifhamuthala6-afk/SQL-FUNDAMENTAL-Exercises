# SQL-FUNDAMENTAL-Exercises

## Overview

This repository contains my handwritten **SQL Fundamentals exercises and notes**, documenting my learning journey as I build a strong foundation in SQL for **data analytics and database querying**.

The exercises focus on developing practical SQL skills through hands-on practice, covering essential concepts used in real-world data analysis.

## Topics Covered

- SQL fundamentals
- `SELECT` statements
- `WHERE` filtering
- `ORDER BY` sorting
- `GROUP BY` and `HAVING`
- Aggregate functions such as:
  - `COUNT()`
  - `SUM()`
  - `AVG()`
  - `MIN()`
  - `MAX()`
- SQL operators
- Date and time functions
- String functions
- Conditional logic using `CASE`
- Data filtering and analysis
- Basic data transformation

## Purpose

The purpose of this repository is to:

- Strengthen my SQL fundamentals
- Practice writing and understanding SQL queries
- Develop problem-solving skills for data analysis
- Document my progress and learning journey
- Build a foundation for more advanced SQL and data analytics projects
